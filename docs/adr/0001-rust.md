# ADR-0001: Rust as the implementation language

- Status: accepted
- Date: 2026-10-12

## Context

Loom is a CLI, a long-running daemon on a laptop, a TUI and an MCP server. Its value rests on a fully typed interface for agents. The domain is made of closed sets: task kinds, statuses, events, proposed actions, autonomy classes, runtime capabilities, gate results. Go was the main alternative (official SDKs for Anthropic and Datadog, Bubble Tea, goreleaser, faster iteration). TypeScript only made sense with the Agent SDK, which loom does not use. Python was excluded by distribution and daemon footprint.

## Decision

Rust for every component. No second language.

## Consequences

- Closed sets are enums with data; exhaustive matching makes the compiler list every place to update when a variant is added.
- `serde` + `schemars` generate CLI `--json` schemas, MCP tool schemas and agent contracts from the same types.
- Single static binary, small footprint.
- No official Anthropic Rust SDK (official SDKs: Python, TypeScript, C#, Go, Java, PHP, Ruby): the direct-API runtime needs a thin typed HTTP client. Same for Jira, GitLab and GitHub, where loom writes thin clients for the endpoints it uses.
- Slower compile times and iteration than Go.
