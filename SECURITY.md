# Security policy

## Supported versions

Loom is before 1.0. Only the latest release of the `stable` channel receives security fixes.

## Reporting a vulnerability

Do not open a public issue. Report it privately through GitHub: **Security** tab of this repository, then **Report a vulnerability**.

Include the affected version (`loom version --json`), the platform, the steps to reproduce and the impact you expect. Reports are acknowledged as soon as possible; this is a personal project maintained on a best-effort basis.
